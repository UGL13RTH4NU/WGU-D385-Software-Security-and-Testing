# WGU D385: Software Security and Testing

A repository of resources and learning strategies I used to successfully complete **WGU D385 v2**.

## 🚀 Getting Started

If you are just beginning the course, I highly recommend starting with the **(Really) Rough Guide** by Reddit user *Vuxerius*. It was incredibly helpful in understanding the scope and expectations of the assignments.

## 📚 Helpful Resources

To complete the tasks effectively, you'll need a solid grasp of error handling and assertions in Python. The guide mentioned above referenced these excellent tutorials which I used extensively:

* [W3Schools: Python Try Except](https://www.w3schools.com/python/python_try_except.asp)
* [W3Schools: Python String Formatting](https://www.w3schools.com/python/python_string_formatting.asp)
* [W3Schools: Python String Reference](https://www.w3schools.com/PYTHON/python_ref_string.asp)
* [W3Schools: Python Assert Keyword](https://www.w3schools.com/python/ref_keyword_assert.asp)
* [Towards Data Science: Practical Python - Try, Except, and Assert](https://towardsdatascience.com/practical-python-try-except-and-assert-7117355ccaab/)

## 🤖 AI Learning Prompt

It had been over two years since I last wrote any Python code, so I used Claude to help tutor me back up to speed. 

If you are in a similar situation and want to use an AI assistant to help you *learn* (rather than just doing the work for you), feel free to copy and paste the prompt I used below:

> **My AI Tutor Prompt:**
> 
> Hi Claude,
> 
> I created this project to assist me with my WGU D385 Software Security and testing Class. We are going to start with Task 1. It's been a while since I've touched Python so I will probably need your assistance in understanding and completing my assignment.
> 
> **1 important thing for you to remember is I do not want you to do the work for me.** I may need assistance, and even step-by-step instructions to help me do it myself. But it is important to me that I do the assignment myself.
> 
> I've done 2 python classes previously, but it's been so long since I did them that I have forgotten most of how to do it. So when I ask for help or how to do something please assume that I am mostly new to Python and need detailed instructions for assistance. Please explain things as we go. Tell me why we do something the way we do it. Also repeatedly explain syntax rules/ indentation rules, and any other "Rules" I may need to know to become at least knowledgeable in Python programming.
> 
> One of the things I have problems with is distinguishing between things that must be called or written in a definitive manner, versus those that are up to a code writers discretion. Please be sure to distinguish these things when we code together and explain them to me and why they are done the way they are done.



Also, a lot of what I did was copy the style that you find in the app_student.py; IMO, WGU instructors made it very easy for us with all the comments in the Code they left us.
